# Xiangqi Web

Bộ khung website Cờ Tướng theo kiến trúc Frontend - Backend tách biệt.

## Công nghệ dự kiến

- Frontend: HTML5, CSS3 và Vanilla JavaScript.
- Backend: Node.js, Express.js và REST API.
- Database: Microsoft SQL Server thông qua package `mssql`.
- Realtime: Socket.IO ở giai đoạn phát triển online.

## Thư mục chính

- `frontend/`: giao diện và mã phía trình duyệt.
- `backend/`: REST API và các tầng xử lý phía máy chủ.
- `database/`: script SQL và sơ đồ dữ liệu dự kiến.
- `docs/`: tài liệu kiến trúc, API, dữ liệu, luật chơi và roadmap.

> Hiện tại project chỉ có cấu trúc và tài liệu khung; chưa triển khai chức năng, kết nối database, authentication hay Socket.IO.

# Kế hoạch phát triển

## Phase 1 - Project Structure

Khởi tạo cấu trúc Frontend, Backend, Database và Documentation.

## Phase 2 - Frontend Layout

Chuẩn bị bố cục giao diện frontend.

## Phase 3 - Chess Board

Xây dựng bàn Cờ Tướng 9x10.

## Phase 4 - Chess Pieces

Hiển thị các quân cờ Đỏ và Đen.

## Phase 5 - Piece Movement

Triển khai di chuyển cho từng loại quân.

## Phase 6 - Game Rules

Triển khai các luật hợp lệ của Cờ Tướng.

## Phase 7 - Game State

Quản lý lượt chơi và trạng thái ván đấu.

## Phase 8 - Check / Checkmate

Kiểm tra chiếu Tướng và chiếu bí.

## Phase 9 - Backend Setup

Khởi tạo Node.js và Express.js.

## Phase 10 - REST API

Xây dựng các nhóm REST API.

## Phase 11 - SQL Server

Thiết lập SQL Server và package `mssql`.

## Phase 12 - Authentication

Xây dựng đăng ký, đăng nhập và phân quyền cần thiết.

## Phase 13 - Game History

Lưu và hiển thị lịch sử trận đấu.

## Phase 14 - Leaderboard

Xây dựng bảng xếp hạng người chơi.

## Phase 15 - Socket.IO

Thiết lập lớp giao tiếp realtime.

## Phase 16 - Online Multiplayer

Xây dựng phòng chơi và chế độ nhiều người chơi online.

## Phase 17 - Testing

Kiểm thử frontend, backend, luật chơi và tích hợp.

## Phase 18 - Deployment

Đóng gói và triển khai hệ thống.

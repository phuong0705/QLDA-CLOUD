# Thiết kế REST API dự kiến

> Các endpoint dưới đây mới là nhóm chức năng dự kiến, chưa được triển khai.

## Authentication API

Base path dự kiến: `/api/auth`.

## User API

Base path dự kiến: `/api/users`.

## Game API

Base path dự kiến: `/api/games`.

## Ranking API

Base path dự kiến: `/api/rankings`.
